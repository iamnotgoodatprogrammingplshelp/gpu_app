# C++ GPU Viewer

A simple C++ command-line application that displays basic information about your system's GPU.

## Features

- Detects installed GPU
- Shows GPU name
- Displays vendor information
- Shows driver version
- Displays total VRAM

## Requirements

- C++17 or newer
- GCC / Clang / MSVC
- CMake (optional)

## Build

### Using CMake

```bash
mkdir build
cd build
cmake ..
cmake --build .
